# Code of conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent. Assume good faith, argue about the code rather than the
person, and accept that "I was wrong" is a normal and useful thing to say — this
codebase's history contains several of them, recorded on purpose.

Report unacceptable behaviour through
[a private security advisory](https://github.com/piwi3910/truenas-csi/security/advisories/new)
or by contacting the maintainer directly.
